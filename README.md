## Applications

### Log Output

A Python application that generates a random UUID at startup and prints it alongside a UTC timestamp every 5 seconds.

The application runs in a Docker container deployed to a local Kubernetes cluster using k3d.

See the [Log Output README](log_output/README.md) for setup and deployment instructions.
